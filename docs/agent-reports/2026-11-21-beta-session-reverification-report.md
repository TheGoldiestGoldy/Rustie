## 4. Limits

Physical playback, audible transition quality, hardware XRUNs and stress with several external instrument slots still need verification. Scene timing measurements in this report refer to render frames. Structural edits or launching Session from an active Arrangement can rebuild playback. Session audio loop boundaries follow musical time, and playback uses the decoded samples at their original speed.
